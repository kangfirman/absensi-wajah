Langkah 1: Verifikasi Identitas

Masukkan NIS dan token kelas dari wali kelas Anda.

Langkah 2: Persetujuan (Informed Consent)

Penggunaan data wajah untuk absensi.

• Sistem menyimpan data numerik pemetaan wajah (bukan foto) untuk mencocokkan Anda saat absen.
• Data hanya dapat diakses guru/admin sekolah dan dipakai hanya untuk absensi.
• Anda atau orang tua/wali dapat meminta penghapusan data kapan saja lewat wali kelas.
• Jika keberatan, Anda tetap dapat diabsen secara manual oleh guru.
